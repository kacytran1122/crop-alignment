Abstract:
Some segmentation benchmarks label each image crop independently. That can create a hidden shortcut. The same location in the original scene may appear in two overlapping crops, but the automatic labelling rule may assign different labels because it was fitted separately inside each crop window. A model can then look strong on the benchmark by following the crop-specific label, even when it has not learned the real object or surface the benchmark is meant to measure.

We introduce crop-label alignment, a simple test for this shortcut. The test focuses only on places where overlapping crops disagree. It asks whether the model follows the label attached to the crop it is currently reading more often than labels assigned by other crops covering the same place. If a model truly ignores crop context, the test should show no crop-label alignment.

We evaluate the test in settings where crop dependence can be controlled, then apply it to remote-sensing segmentation benchmarks with automatic labels. The results show that crop-dependent labelling can create measurable shortcuts, and that ordinary patch-based scoring can reward models for learning those shortcuts.

The method is intentionally narrow. It does not prove that every automatic label is flawed, and it does not detect shortcuts unrelated to crop windows. Its purpose is to give reviewers and benchmark builders a practical audit for one important failure mode before trusting model comparisons.
